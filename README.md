# Сигнал — монитор упоминаний

Локальное Windows-приложение и серверная веб-панель. Общий поиск выполняется через Яндекс, найденные страницы сайтов проверяются по ключевому запросу, а результаты сохраняются встроенным модулем `node:sqlite` и экспортируются в TXT/XLSX/CSV.

## Установка готовой программы

- Требуется Windows 10/11 x64 и установленный Яндекс Браузер.
- [Скачайте последнюю Windows-сборку](https://github.com/LearnFlowCore/FindIFM/releases/latest/download/Signal-Setup-1.0.0.exe).
- Запустите `Signal-Setup-1.0.0.exe`.
- Выберите папку установки и завершите мастер. Права администратора не требуются.
- Откройте «Сигнал» через меню «Пуск» или ярлык рабочего стола.
- Node.js, npm и исходный код на компьютере пользователя не нужны.

Установщик пока не подписан коммерческим сертификатом, поэтому Windows SmartScreen может запросить дополнительное подтверждение издателя.

## Данные программы

База, логи, уникальный временный профиль браузера и экспорты находятся в `%APPDATA%\Signal`. Для каждого запуска создаётся отдельный профиль, поэтому оставшееся окно Яндекс Браузера не блокирует новый поиск. Они не записываются в `Program Files` и сохраняются при удалении программы.

## Запуск из исходников

1. Клонируйте репозиторий и дважды откройте `start_monitor.cmd`.
2. Если Node.js не установлен, скрипт скачает переносную версию в `.runtime` без прав администратора.
3. При первом запуске скрипт автоматически выполнит `npm install`.
4. Панель откроется по адресу <http://127.0.0.1:3080>.
5. Не закрывайте консоль и окно Яндекс Браузера во время парсинга.

Ручной запуск:

```powershell
git clone https://github.com/code-spark-pro/mention-monitor-windows.git
cd mention-monitor-windows
npm install
npm test
npm start
```

## Render

Репозиторий содержит `render.yaml` и `Dockerfile` для серверного запуска. Render
устанавливает Chromium и запускает его в фоновом режиме. Бесплатный план хранит
SQLite, логи и экспорты во временной файловой системе. Изменения ветки `main`
развёртываются автоматически.

### Поиск по смыслу и сводка ИИ

Для включения задайте **на сервере** переменную окружения `AI_API_KEY` от
провайдера с OpenAI-совместимым API. По умолчанию используются
`https://api.openai.com/v1`, эмбеддинги `text-embedding-3-small` и языковая
модель `gpt-4.1-mini`. Для другого совместимого провайдера задайте
`AI_BASE_URL`, `AI_EMBEDDING_MODEL` и `AI_CHAT_MODEL`. Ключ не передаётся
браузеру. Без него обычный поиск работает, а режим по смыслу и сводка
показывают сообщение о необходимой настройке.

Отметьте «Поиск по смыслу» перед запуском. Приложение получает адреса только
через Яндекс, затем оценивает смысловую близость выдержек: до 80 найденных
страниц, до 4 фрагментов с начала каждой, до 30 результатов. «Сводка ИИ»
использует до 12 сохранённых выдержек и показывает нумерованные ссылки на
источники. Выдержки архивных запусков сохраняются в IndexedDB браузера;
серверная SQLite бесплатного Render может быть очищена при развёртывании.
Модель не определяет отсутствующие даты. Внешний API может быть платным.

Источником поисковой выдачи служит только Яндекс. Если Яндекс требует CAPTCHA,
в разделе «Результаты» нажмите «Открыть CAPTCHA в отдельном окне». В новом окне
изображение браузера можно увеличить, нажимать и перетаскивать элементы; текст и
клавиши передаются в фоновый Chromium на Render. После подтверждения поиск
продолжается автоматически. На решение есть 15 минут. Не закрывайте основную вкладку
до открытия окна проверки; само окно можно перезагружать во время активной задачи.
В Windows-приложении проверку можно пройти в окне браузера.
Кнопка «Остановить поиск» доступна рядом с запуском и над результатами во время задачи.

После успешного поиска результаты с ключевой фразой и датой автоматически попадают
в раздел «Сохранённое». Запуск из «Истории» также можно сохранить вручную.
Архив хранится в IndexedDB этого браузера, поэтому переживает повторное развёртывание
на бесплатном Render; на другом устройстве он не появится. Для переноса или резервной
копии скачайте CSV нужного запуска из раздела «Сохранённое». Очистка данных браузера
удалит местный архив.

Для ручного создания сервиса используйте Render Blueprint из репозитория
`LearnFlowCore/FindIFM`.

Desktop-режим для разработчика и сборка установщика:

```powershell
npm install
npm test
npm run desktop
npm run dist:win
```

Если GitHub CDN недоступен в текущей сети, перед сборкой можно задать зеркала загрузки:

```powershell
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR = 'https://npmmirror.com/mirrors/electron-builder-binaries/'
npm run dist:win
```

Автообновление desktop-версии работает через GitHub Releases. Для выпуска новой
версии увеличьте `version` в `package.json`, создайте и отправьте тег вида `v1.0.1`:

```powershell
git tag v1.0.1
git push origin v1.0.1
```

Workflow `Publish Windows release` соберёт установщик, `latest.yml` и blockmap.
Установленная программа проверяет релизы при запуске и затем каждые шесть часов.

## Поиск

- Парсер открывает общую веб-выдачу Яндекса, без переключения на вкладку «Новости».
- Найденные страницы открываются и проверяются по полному тексту ключевого запроса.
- На каждом сайте можно дополнительно проверить внутренние страницы до двух переходов; лимит задаётся в поле глубины обхода.
- Произвольный текст передаётся в Яндекс без кавычек. Все слова должны присутствовать, но порядок и словоформы могут отличаться.
- Аббревиатуры длиной до пяти букв, например `РЦВДО`, проверяются целиком без учёта регистра.
- «Точная фраза» обрамляет весь текст кавычками, требует строгое совпадение без словоформ и отключает извлечение даты.
- Поддерживаются даты `ДД.ММ.ГГГГ`, `ГГГГ-ММ-ДД`, `ДД месяц ГГГГ`.
- Ручной диапазон перекрывает период и дату из запроса.
- Дата из запроса с периодом создаёт симметричный диапазон вокруг даты.
- Период без даты передаётся через `within`.
- Каждый сюжет загружается и проверяется по всем словам либо по точной фразе. В таблицу сохраняются прямые ссылки сайтов-источников, а не URL агрегатора Дзена.
- Результаты группируются по ключевому упоминанию; итоговая строка показывает количество публикаций и уникальных сайтов.
- Отдельный результат можно удалить кнопкой в его строке.
- Дата берётся из метатегов, `<time>` или сниппета и проверяется повторно.
- Whitelist и blacklist передаются операторами `site:`/`-site:` и применяются повторно к URL.
- Результаты каждого запуска сохраняются в SQLite, общий TXT `FindIFM.txt` и отдельный TXT-снимок с датой и идентификатором запуска.
- В интерфейсе доступны быстрый тест одной страницы, предпросмотр первых строк, прогресс, ETA и остановка поиска.

При SmartCaptcha вкладка остаётся открытой. В режиме «остановить» приложение опрашивает DOM каждые две секунды и продолжает после прохождения капчи; в режиме «пропустить» текущая страница выдачи пропускается.

## Профили

- **Временный**: уникальный каталог `data/browser-profile-<process>-<random>` для каждого экземпляра, выбран по умолчанию.
- **Пользовательский**: путь задаётся в панели. Перед использованием закройте обычные окна Яндекс Браузера, иначе профиль может быть заблокирован.

## API

- `GET /api/status` — интернет, браузер и путь к нему;
- `POST /api/search` — запуск, ответ `202 {jobId}`;
- `GET /api/jobs/:id` и `GET /api/search/:id` — состояние задания;
- `GET /api/results` — `page`, `limit`, `sort`, `order`, `q`, `includeUnknownDate`, `jobId`; ответ содержит строки и агрегаты по запросу;
- `GET /api/history`, `POST /api/history/:id/rerun`, `DELETE /api/history`;
- `GET/POST/PUT/DELETE /api/presets`;
- `GET/PUT /api/settings`;
- `POST /api/export` — `{scope:"current"|"all",jobId}`;
- `DELETE /api/results/:id` — удалить отдельный результат;
- `DELETE /api/results` — удалить все результаты.

Сервер слушает только `127.0.0.1`. Офлайн-режима нет: перед каждым заданием выполняется запрос к `https://ya.ru` с тайм-аутом пять секунд, а состояние обновляется каждые десять секунд.

В desktop-режиме Windows назначает случайный свободный локальный порт, а API требует случайный 256-битный токен текущего запуска. Одновременно работает только один экземпляр программы. Поисковые задания выполняются последовательно, чтобы Яндекс Браузер и его профиль не конфликтовали.

## Хранение и безопасность

При запуске из исходников база находится в `data/mention-monitor.db`, логи в `logs/parser.log`, экспорт в `exports/`. В установленной программе эти каталоги находятся в `%APPDATA%\Signal`. URL нормализуются, UTM/`yclid`/`gclid` удаляются. Значения SQL передаются параметрами. Backend ограничивает размер JSON и не публикуется во внешнюю сеть.

Для будущего Yandex Search API предусмотрен интерфейс `SearchProvider`; текущая реализация называется `YandexHTMLProvider`, заготовка замены — `YandexAPIProvider`.
